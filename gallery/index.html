Sandglass

Homages to the original Prince of Persia (1989), each built by a different agent from the same starting prompt. Choose one and play.

The brief

Make a variation of the original Prince of Persia (1989). Be creative—show what you can do. Use the web if it helps. You may manage dependencies with mise. If you want an image-generation API, ask and I’ll give you an OpenRouter key.

Each run started in an empty folder with an OpenRouter key in .env and its own fixed dev port, so the models could work in parallel without stepping on each other.
