Sandglass

Four from-scratch takes on the original Prince of Persia (1989). Pick a generation and play.

The brief

make a variation of the original prince of persia 1989 video game, be creative, show off what you can do, up to you if you want to use web or not, you can use mise to manage the project dependencies, if you want image gen api let me know and i can give you an open router key

Eval shells also pointed models at .env / OPENROUTER_API_KEY and a fixed DEV_PORT so parallel runs wouldn’t collide.
